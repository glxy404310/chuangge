# 窗格（Chuangge）

一款极简轻量的 macOS 顶部菜单栏窗口收纳与速找工具。

打开十几个窗口时，传统的强制等分平铺会把应用压变形、满屏缩略图反而更难找窗口。**窗格**换了一种更顺手的思路：**绝不强行改变任何窗口尺寸**，用「一键无损收桌面 + 顶部栏秒级找窗」帮你保持桌面清爽、1 秒直达目标窗口。

---

## 核心特性

### 1. 无损整理桌面（绝不强行缩放窗口）
- **一键专注**：保留当前正在使用的窗口，一键收起其余所有杂乱窗口。在设置中可自由选择两种收起策略：
  - **最小化其他窗口**（默认）：按窗口粒度，同应用的其他窗口也会收进程序坞，只留当前这 1 个窗口。
  - **隐藏其他应用**：按应用粒度（`⌘H` 风格），恢复极快且不占用程序坞空间。
- **错落排齐**：保持每个窗口原本的宽高不变，按屏幕分组整齐错落排开、露出每个窗口的标题栏，并自动做屏幕边界夹紧；间距支持 `紧凑 (24pt)` / `适中 (32pt)` / `宽松 (44pt)` 三档。
- **一键撤销**：无论是「一键专注」还是「错落排齐」，都可以随时一键还原整理前的窗口位置与显示状态。

### 2. 顶部栏秒级找窗
- **贴合菜单栏的圆角毛玻璃卡片**：左键点击顶部菜单栏图标即刻弹出，自动聚焦搜索框，支持按**应用名 + 窗口标题**实时过滤（支持多关键词与中文输入法组合态保护）。
- **收起也能随时召回**：同时索引可见窗口、已最小化窗口和已隐藏应用的窗口，收纳之后依然能在列表里搜到并一键切回。
- **两种浏览视图**：
  - **按应用分组**（默认）：最近使用过的应用自动排在最前，一眼区分同一个浏览器或编辑器里的多个窗口，支持按应用一键隐藏/显示。
  - **最近使用**：按系统窗口层级（Z-order）扁平排列，方便在最近切过的窗口间快速跳转。
- **列表内随手清理**：悬停或键盘选中任意窗口即可直接执行「切入并专注」「收起/恢复」「关闭窗口」。

### 3. 纯原生、零依赖、完全离线
- 基于 Swift、AppKit 与 SwiftUI 原生编写，无任何第三方依赖，常驻顶部菜单栏几乎不占资源。
- **零联网、零数据上报**：仅通过 macOS 本地辅助功能接口读取与管理窗口。

## 操作与快捷键

- **左键点击顶部栏图标**：打开 / 关闭找窗面板
- **右键（或 `Control + 点击`）顶部栏图标**：快捷菜单（一键专注 / 错落排齐 / 撤销上次整理 / 设置 / 退出）

在找窗面板内支持全键盘操作：

| 快捷键 | 功能 |
|---|---|
| 直接打字 | 实时搜索应用名或窗口标题（支持空格分隔多关键词） |
| `↑` / `↓` | 在窗口列表中上下移动选中项 |
| `Enter` | 切入选中窗口（自动取消隐藏/最小化并置顶） |
| `⌘ + Enter` | **切入并专注**：切到选中窗口，同时收起其余所有窗口 |
| `Esc` | 有搜索词时清空搜索；无搜索词时关闭面板（设置页返回列表） |

## 安装与使用

### 方式一：下载预编译版本（推荐）

1. 前往本仓库的 [Releases](https://github.com/glxy404310/chuangge/releases) 页面，下载最新版的 `Chuangge-v2.0-macOS-arm64.zip`。
2. 解压后，将 **`窗格.app`** 拖入 `应用程序`（`/Applications` 或 `~/Applications`）文件夹并双击启动。
3. **如遇 macOS 提示“无法验证开发者”或“已损坏”**（因本地免费分发未购买 Apple 开发者公证），可在终端执行一次以下命令解除下载隔离属性后再打开：
   ```bash
   xattr -dr com.apple.quarantine "/Applications/窗格.app"
   ```
   （如果你放在了 `~/Applications`，请把路径替换为 `~/Applications/窗格.app`。）

### 方式二：从源码本地编译

需要已安装 Xcode 或 macOS Command Line Tools（`xcode-select --install`）：

```bash
git clone https://github.com/glxy404310/chuangge.git
cd chuangge
./test.sh   # 运行单元测试
./build.sh  # 编译并打包到 build/窗格.app
open "build/窗格.app"
```

> **开发小技巧（避免重编后反复重新授权）**：默认 `./build.sh` 使用本地临时签名（`-`），每次重编都会变化签名哈希。你可以在 macOS「钥匙串访问 → 证书助理 → 创建证书」中创建一个「代码签名」证书，然后用 `SIGN_IDENTITY="你的证书名" ./build.sh` 构建，后续更新将自动保留辅助功能权限。

## 首次启动：开启辅助功能权限

窗格需要 macOS **辅助功能（Accessibility）** 权限来读取窗口标题并移动/收起窗口：

1. 点击顶部栏的「窗格」图标，点击面板中的 **打开辅助功能设置**。
2. 在「系统设置 → 隐私与安全性 → 辅助功能」中，点 **＋** 添加 `窗格.app` 并开启开关。
3. 授权生效后，面板会自动刷新并展示你当前的所有窗口。

> 如果覆盖升级了新版本后发现仍停留在授权引导页，请在「辅助功能」列表中先选中旧条目点 **－** 删除，再重新添加新版本即可。

## 系统要求

- macOS 15.0 及以上
- 预编译 Release 包适用于 Apple Silicon（M 系列芯片）；Intel Mac 可直接克隆源码运行 `./build.sh` 本地编译。
